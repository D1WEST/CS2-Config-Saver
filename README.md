# CS2 Config Saver (by DIWEST)

Утилита для оперативного сохранения, резервного копирования и автоматического применения игровых конфигураций (конфигов) для Counter-Strike 2. 
### [📥 Скачать последнюю версию для Windows (64-bit)](https://github.com/D1WEST/CS2-Config-Saver/releases/latest)

Программа собирает разрозненные пользовательские файлы настроек, привязок клавиш и переменных из профиля Steam, объединяет их в классический единый файл `.cfg` и позволяет автоматически загрузить его обратно в игру без необходимости ручного переноса файлов и рутинного ввода команд в консоли.

## Основной функционал

* **Объединение настроек (Парсинг vcfg):** утилита находит файлы `cs2_machine_convars.vcfg`, `cs2_user_convars.vcfg` и `cs2_user_keys.vcfg` вашего активного профиля, очищает их от системного синтаксиса и преобразует в стандартные консольные команды (`bind "клавиша" "действие"` и `переменная "значение"`).
* **Автоматическое определение профилей:** программа сканирует установленный клиент Steam, находит папку `userdata` и предлагает выбрать нужный SteamID (если на компьютере играет несколько человек).
* **Интеграция с игрой:** при импорте сохраненного конфига утилита копирует его в рабочий каталог CS2, переводит игру на передний план, открывает консоль разработчика и отправляет команду `exec`.
* **Работа из системного трея:** программа работает в фоновом режиме, сворачивается в трей при потере фокуса и не мешает игровому процессу.

## Как пользоваться приложением (Пошаговое руководство)

### Этап 1. Подготовка конфигурации в игре
1. Запустите Counter-Strike 2.
2. Откройте консоль разработчика (клавиша `~` по умолчанию) и введите команду:
   ```cmd
   host_writeconfig
   ```
   *Это принудительно заставит игру обновить локальные файлы настроек на жестком диске актуальными данными из оперативной памяти.*

### Этап 2. Сохранение (резервное копирование) конфига
1. Запустите утилиту **CS2 Config Saver**.
2. Если вы запускаете программу впервые, нажмите кнопку **Найти папки Steam** (Find Steam Folders). Программа автоматически определит путь. 
   * *Если на компьютере зарегистрировано несколько аккаунтов, выберите нужный Steam ID во всплывающем списке.*
3. Убедитесь, что в поле **Папка бэкапов** (в самом низу окна) указан желаемый путь для хранения файлов. Вы можете изменить его, дважды кликнув по строке пути.
4. Нажмите кнопку **Сохранить текущий конфиг** (Save current config).
5. Введите имя конфигурации (используйте только латинские или кириллические буквы без спецсимволов) и нажмите **Сохранить** (Save).
6. В папке бэкапов появится папка с именем вашего конфига, содержащая:
   * Объединенный рабочий файл `ИмяКонфига.cfg`.
   * Папку `/raw/` с оригинальными нетронутыми резервными копиями файлов `.vcfg`.

### Этап 3. Перенос и запуск конфига в игре
Если вы переустановили игру, сбросили настройки или хотите применить ранее сохраненный конфиг:
1. Запустите Counter-Strike 2.
2. В главном меню утилиты нажмите **Добавить конфиг в CS2** (Add config to CS2).
3. В открывшемся окне проводника выберите нужный файл `.cfg` из папки ваших бэкапов.
4. Утилита самостоятельно скопирует файл в игровой каталог (`.../game/csgo/cfg/`).
5. Начнется 7-секундный обратный отсчет, после чего программа переведет CS2 на передний план, откроет консоль и автоматически введет:
   ```cmd
   exec ИмяВашегоКонфига
   ```

## Возможные ошибки и способы их решения

В процессе работы утилиты из-за особенностей взаимодействия программ в Windows могут возникать непредвиденные ситуации. Ниже описаны наиболее распространенные из них:

### 1. Консоль в игре не открывается, команды не вводятся автоматически
* **Причина А:** В настройках самой Counter-Strike 2 отключена консоль разработчика.
  * *Решение:* Зайдите в настройки CS2 -> вкладка «Игра» -> пункт «Включить консоль разработчика (~)» -> выберите **«Да»**.
* **Причина Б:** Конфликт уровней привилегий (UIPI в Windows). Если Steam или CS2 запущены «От имени Администратора», операционная система из соображений безопасности блокирует любые клавиатурные команды, отправляемые обычными утилитами.
  * *Решение:* Запускайте утилиту **CS2 Config Saver** также «От имени Администратора».
* **Причина В:** В игре назначена нестандартная клавиша открытия консоли, которую программа не смогла прочитать из файла настроек.
  * *Решение:* Откройте консоль в игре вручную (нажав настроенную вами клавишу в CS2) перед тем, как нажимать кнопку отправки команды в утилите, либо вставьте команду из буфера обмена вручную (комбинацией `Ctrl + V` и нажатием `Enter`).

### 2. Ошибка «Steam path not defined» / «Steam не найден»
* **Причина:** Клиент Steam установлен по нестандартному пути, либо отсутствуют необходимые записи в системном реестре Windows.
  * *Решение:* Нажмите кнопку **Найти папки Steam**, во всплывающем окне выберите ручной выбор и укажите путь к корневой папке, где установлен Steam (например, `D:\Games\Steam`), либо укажите напрямую путь к папке настроек профиля (заканчивающейся на `.../730/local/cfg`).

### 3. Зависание или вылет игры в процессе работы скрипта
* **Причина:** Использование устаревших механизмов эмуляции ввода (вроде `SendKeys.SendWait`), конфликтующих со службами DirectInput или античитом VAC.
  * *Решение:* В текущей версии приложения эта уязвимость минимизирована благодаря переходу на аппаратный низкоуровневый WinAPI-ввод `keybd_event`. Убедитесь, что вы используете актуальную версию утилиты.

### 4. Некорректные символы при вводе имени конфигурации
* **Причина:** Попытка использовать в имени файла зарезервированные системные символы (`/`, `\`, `*`, `?`, `:`, `|` и др.).
  * *Решение:* Поле ввода имеет встроенный фильтр. Допускается использование только букв русского/английского алфавита и пробелов.
